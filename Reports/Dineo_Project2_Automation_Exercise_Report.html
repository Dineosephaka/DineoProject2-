1. Project Overview

This project automates an end-to-end e-commerce customer journey on the Automation Exercise website using Java, Selenium WebDriver, TestNG and the Page Object Model (POM). The workflow validates registration, login, product search, product verification, shopping cart management, checkout, order confirmation and account deletion.

The primary evidence is the validated continuous end-to-end workflow, successfully executed in both Google Chrome and Microsoft Edge.

8. Key Automation Features

  • Page Object Model: Separates page locators and actions from test logic.
  • Reusable driver setup: DriverFactory supports Chrome, Edge and Firefox.
  • Unique test data: Timestamp-based email generation prevents registration conflicts.
  • Reusable actions: Login, logout, product search, cart operations and account deletion are encapsulated in page objects.
  • Explicit waits: Used for dynamic page elements and cart updates.
  • Failure screenshots: BaseTest captures a screenshot when a test fails.
  • Cross-browser execution: The complete workflow passed on Chrome and Edge.
  • Maven execution: Tests are repeatable through Maven.
